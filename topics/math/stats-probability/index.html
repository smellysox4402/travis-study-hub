4.1

Data & sampling

Where data comes from, whether it's trustworthy, and the words for what can go wrong.

POPULATION, SAMPLE, TYPES OF DATA

TermMeaning
PopulationThe whole group you're interested in (all students in HK).
SampleA subset of the population you actually measure.
Random sampleEvery member equally likely to be chosen — the gold standard.
Discrete dataCountable, separate values (number of siblings: 0, 1, 2…).
Continuous dataAny value on a scale (height, time, mass).

RELIABILITY & BIAS (4.1)

  • Bias = a sampling method that systematically over/under-represents a group.
  • Outlier = a value far from the rest — investigate before you trust the mean.
  • Sampling techniques: simple random, stratified (by group), systematic (every k-th), convenience (easy but biased), quota, self-selected (voluntary → biased).

Exam line: "the sample is not representative because …", "selection bias / under-coverage / self-selection".

4.2 · 4.3

Summarising data

Centre and spread — the numbers that describe a whole dataset in a line each.

CENTRE

Mean

x̄ = Σx/n. Uses every value, so it's dragged by outliers.

CENTRE

Median

The middle value when sorted. Robust — ignores outliers.

CENTRE

Mode

The most common value. Grouped data → modal class.

SPREAD

Range & IQR

Range = max − min. IQR = Q3 − Q1 (the middle 50%).

SPREAD

Standard deviation σ

√ of the mean squared deviation. Same units as the data. Smaller σ = more consistent.

SPREAD

Variance σ²

Mean of squared deviations from the mean.

BOX & WHISKER + OUTLIERS

Five-number summary: min, Q1, median, Q3, max. An outlier sits below Q1 − 1.5×IQR or above Q3 + 1.5×IQR.

📟 GDC — 1-variable statistics

  1. MENU → 2 (STAT) → enter data in List 1
  2. F2 (CALC) → F1 (1-VAR)
  3. Set XList = List1, Freq = 1 → EXE
  4. Reads off x̄ (mean), σx (population sd), sx (sample sd), min, Q1, Med, Q3, max

σx vs sx: the exam usually wants the population standard deviation σx. Check which one the question asks for.

EFFECT OF CONSTANT CHANGES (4.3)

Adding/subtracting a constant shifts every measure of centre and position by that amount, but leaves spread (range, IQR, σ) unchanged. Multiplying by k multiplies both centre and spread by k.

4.4

Correlation & regression

How two variables move together, and the line that predicts one from the other.

PEARSON'S r & THE REGRESSION LINE

r scores correlation from −1 to +1: sign = direction, |r| = strength. r = −0.9 is a tighter link than r = +0.4.

The regression line y on x (least squares) predicts y from x. It's only valid inside the range of the data — predicting beyond is extrapolation.

📟 GDC — regression line + r

  1. MENU → 2 (STAT) → x-values in List 1, y-values in List 2
  2. F2 (CALC) → F3 (REG) → F1 (X, linear)
  3. Reads off a, b, and r

⚠️ Casio writes y = a + bx (a = intercept, b = gradient). IB writes y = ax + b. Match by the numbers — the gradient multiplies x.

CORRELATION ≠ CAUSATION: ice-cream sales and drownings both rise in summer — huge r, but a third variable (heat) drives both. Exam line: "correlation does not imply causation; a confounding variable may explain the link."
4.5 · 4.6

Probability

The three laws of combining events, and the diagrams that make them visible.

THE BASICS

P(A) = n(A)/n(U)  ·  complementary: P(A′) = 1 − P(A)

  • Mutually exclusive (can't both happen): P(A ∪ B) = P(A) + P(B).
  • Combined events (general): P(A ∪ B) = P(A) + P(B) − P(A ∩ B).
  • Independent (one doesn't affect the other): P(A ∩ B) = P(A) × P(B).
  • Conditional ("given that"): P(A | B) = P(A ∩ B) / P(B).

Trigger words: "and" = ∩ (multiply if independent) · "or" = ∪ (add, minus overlap) · "given that" = conditional.

VENN DIAGRAMS & TREE DIAGRAMS

Venn = groups overlapping (good for ∪ and ∩). Tree = events in sequence (good for conditional and dependent chains — multiply along the branches). Sample-space diagrams and tables of outcomes do the same job for two-step experiments.

EXAM TRAP: P(A | B) ≠ P(B | A). "Probability it's raining given the ground is wet" is not "probability the ground is wet given it's raining". Don't swap them.
4.7 · 4.8

Discrete random variables & binomial

Putting numbers and probabilities together, then the classic count-of-successes distribution.

DISCRETE RANDOM VARIABLES (4.7)

A random variable X takes values each with a probability. Its expected value (mean) is:

E(X) = Σ x · P(X = x)

Worked: X = 1 (0.3), 2 (0.5), 3 (0.2) → E(X) = 1(0.3) + 2(0.5) + 3(0.2) = 1.9.

📟 GDC — expected value

  1. MENU 2 (STAT) → x-values in List 1, P(X=x) in List 2
  2. F2 (CALC) → F1 (1-VAR) → XList = List1, Freq = List2 → EXE
  3. The mean x̄ = E(X)

BINOMIAL DISTRIBUTION (4.8)

X ~ B(n, p): P(X = x) = C(n, x) pˣ (1 − p)ⁿ⁻ˣ

Mean = np · Variance = np(1 − p).

  • Conditions: fixed n · independent trials · two outcomes (success/fail) · same p every trial.
  • Binomial CDF gives P(X ≤ x) — the cumulative "up to and including x".

📟 GDC — binomial probabilities

  1. MENU 2 (STAT) → F5 (DIST) → F5 (BINM)
  2. F1 (Bpd) for exactly P(X = x) · F2 (Bcd) for P(X ≤ x)
  3. Enter x, Numtrial n, p → EXE

P(X > x) = 1 − P(X ≤ x), and P(X ≥ x) = 1 − P(X ≤ x − 1). Use the CDF (Bcd) for "at most / at least".

4.8 · 4.9

The normal distribution

The bell curve, the 68-95-99.7 rule, and working it backwards with inverse normal.

NORMAL DISTRIBUTION N(μ, σ²)

z = (x − μ) / σ

  • 68% of data within μ ± σ · 95% within μ ± 2σ · 99.7% within μ ± 3σ.
  • NormalCDF finds P(a < X < b) — the area under the curve.
  • Inverse normal (InvN) works backwards: probability → x.

📟 GDC — normal & inverse normal

  1. MENU 2 (STAT) → F5 (DIST) → F1 (NORM)
  2. F2 (Ncd) → enter Lower, Upper, σ, μ → EXE for P(Lower < X < Upper)
  3. F3 (InvN) → set Tail, Area, σ, μ → EXE to go probability → x

For a one-sided tail like P(X < 85), set Lower = a very negative number (e.g. −1×10⁹⁹). P(X > x) = 1 − P(X < x).

SPEARMAN'S RANK (4.9)

ρ = 1 − 6Σd² / (n(n² − 1))

Rank both data sets (1 = smallest), square the rank differences d, and plug in. Use Spearman when the relationship is curved or ordinal, or when outliers would wreck Pearson.

Pearson's r is sensitive to outliers (a single extreme point can drag it); Spearman's rank isn't. That's the "limitations" question in 4.9.

4.10 · 4.11

Hypothesis testing

The framework for deciding whether data is significant — chi-squared, the t-test, and p-values.

THE TESTING FRAMEWORK (4.10)

  • H₀ (null) = nothing interesting is happening (no difference, no association).
  • H₁ (alternative) = there IS a difference / association.
  • Significance level α = the threshold (usually 5% = 0.05).
  • p-value = probability of getting results at least this extreme if H₀ were true.
  • Decision: if p < α, reject H₀ (result is significant). If p > α, do not reject H₀.

One-tailed = testing in one direction ("greater than"); two-tailed = either direction ("different"). Two-tailed tests halve the significance in each tail.

CHI-SQUARED (4.10)

χ² = Σ (O − E)² / E

Test for independence: a contingency table of observed frequencies. Degrees of freedom df = (rows − 1)(columns − 1). Compare χ² to the critical value (or use the p-value).

Goodness of fit: compare observed frequencies to an expected distribution.

📟 GDC — chi-squared

  1. MENU 2 (STAT) → F3 (TEST) → F3 (CHI)
  2. F2 (2-WAY) for independence — enter the observed matrix first (Observed: Mat A) → EXE
  3. or F1 (GOF) for goodness-of-fit — give observed & expected lists
  4. Reads off χ², the p-value, and df

To enter the contingency table as a matrix: MENU 1 (RUN·MAT) → F3 (MAT) → set dimensions → type the observed counts.

THE t-TEST (4.10)

Compares the means of two populations. Two-sample t-test: if the p-value < α, the means differ significantly.

📟 GDC — t-test

  1. MENU 2 (STAT) → F3 (TEST) → F2 (t)
  2. F2 (2-Sample) → enter the two data lists (or their stats) → EXE
  3. Reads off t and the p-value → compare p to α
CONCEPT OF A LIMIT (4.11): a limit is the value a function approaches as its input approaches some point — "as x gets closer to a, f(x) gets closer to L", written f(x) → L as x → a. The normal distribution's tails approach (but never reach) zero as x → ±∞.

SELF-TEST ✍

No notes. Pick an answer, get instant feedback.

1. The mean of 2, 4, 6, 8 is:

✅ 5. (2+4+6+8)/4 = 20/4 = 5.
❌ Sum = 20, divided by 4 = 5.

2. The IQR of 1, 2, 3, 4, 5, 6, 7 is:

✅ 4. Q1 = 2, Q3 = 6, so IQR = 6 − 2 = 4.
❌ Q1 = 2 (median of 1,2,3), Q3 = 6 (median of 5,6,7) → IQR = 4.

3. P(A) = 0.4, P(B) = 0.3, P(A ∩ B) = 0.1. Find P(A ∪ B).

✅ 0.6. P(A∪B) = 0.4 + 0.3 − 0.1 = 0.6.
❌ P(A∪B) = P(A) + P(B) − P(A∩B) = 0.6.

4. P(A ∩ B) = 0.2 and P(B) = 0.5. Find P(A | B).

✅ 0.4. P(A|B) = 0.2/0.5 = 0.4.
❌ P(A|B) = P(A∩B)/P(B) = 0.2/0.5 = 0.4.

5. X takes 1 (prob 0.3), 2 (0.5), 3 (0.2). E(X) = ?

✅ 1.9. 1(0.3) + 2(0.5) + 3(0.2) = 1.9.
❌ E(X) = 0.3 + 1.0 + 0.6 = 1.9.

6. X ~ B(10, 0.5). Find P(X = 3).

✅ 0.117. C(10,3)(0.5)¹⁰ = 120/1024 = 0.117.
❌ C(10,3) = 120, × (0.5)¹⁰ = 120/1024 = 0.117.

7. For N(100, 15²), the z-score of x = 130 is:

✅ 2. z = (130 − 100)/15 = 2.
❌ z = (x − μ)/σ = 30/15 = 2.

8. About 68% of a normal distribution lies within:

✅ μ ± σ. 68% within 1σ, 95% within 2σ, 99.7% within 3σ.
❌ 68% = μ ± σ (95% = μ ± 2σ, 99.7% = μ ± 3σ).

🔢 DATA BANK — NUMBERS TO OWN

  • Normal rule: 68% within μ ± σ · 95% within μ ± 2σ · 99.7% within μ ± 3σ
  • Binomial conditions: fixed n · independent · two outcomes · same p
  • r close to ±1 = strong; r near 0 = no linear link; sign = direction
  • Significance: p < α (0.05) → reject H₀; p > α → do not reject
  • df for a chi-squared independence test = (rows − 1)(columns − 1)

🎯 EXAM WALKTHROUGHS

Q1 — CALCULATE [2 marks] "A dataset has mean 50 and standard deviation 4. State the range that holds about 95% of the data."

Model answer: μ ± 2σ = 50 ± 8, so 42 to 58 (2 marks).

Q2 — CALCULATE [3 marks] "X ~ B(10, 0.3). Find P(X ≤ 2)."

Model answer: use the GDC BinomialCDF with n = 10, p = 0.3, x = 2 → 0.383 (method 1, correct setup 1, answer 1).

Q3 — EXPLAIN [2 marks] "r = 0.9 for ice-cream sales vs drowning deaths. What does this NOT tell you?"

Model answer: it does not show that ice cream causes drownings (1) — a confounding variable (hot weather) explains both (1).

Q4 — TEST [4 marks] "A χ² test gives p = 0.02 at the 5% level. State the conclusion."

Model answer: since p = 0.02 < 0.05, we reject H₀ (1) — there is significant evidence of an association/difference at the 5% level (1).

Trap: "reject H₀" is not "prove H₁". Say "significant evidence", never "proven".
