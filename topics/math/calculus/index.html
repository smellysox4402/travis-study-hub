5.1 · 5.2 · 5.3

The derivative

The derivative is the gradient function — and the power rule is the whole game at SL.

THE POWER RULE

d/dx (axⁿ) = an xⁿ⁻¹ — multiply by the power, drop it by one.

  • 3x⁴ → 12x³  ·  2x³ − 5x² + x − 7 → 6x² − 10x + 1
  • Constants vanish: the derivative of −7 is 0.
  • Differentiate a polynomial term by term.

WHAT f′(x) TELLS YOU

Sign of f′(x)Meaning
f′(x) > 0function is increasing (going up)
f′(x) < 0function is decreasing (going down)
f′(x) = 0stationary point (flat — a max, min, or inflection)

The derivative is also a rate of change: "the rate the volume changes" = dV/dt, with units of y per unit of x.

5.4

Tangents & normals

The tangent touches with the curve's own gradient; the normal is perpendicular to it.

TANGENT & NORMAL AT A POINT

  1. Find the gradient m = f′(x₁) at the point.
  2. Find the point's y-value: y₁ = f(x₁).
  3. Tangent: y − y₁ = m(x − x₁).
  4. Normal: gradient −1/m, then y − y₁ = (−1/m)(x − x₁).

Trap: you need BOTH the gradient (from f′) and the point (from f). Skipping the point loses the intercept.

WORKED — tangent

Find the tangent to f(x) = x² at x = 1.

f′(x) = 2x, so m = 2. At x = 1, y = 1. y − 1 = 2(x − 1) → y = 2x − 1.

📟 GDC — gradient at a point (check your derivative)

  1. MENU → 1 (RUN·MAT) → OPTN → F4 (CALC)
  2. F2 (d/dx) → type d/dx(x², 1) → EXE → 2
5.4 · 5.5

Integration & area

Integration is differentiation in reverse — and the definite integral is area.

THE POWER RULE IN REVERSE

∫ axⁿ dx = a·xⁿ⁺¹/(n+1) + c  (n ≠ −1)

  • ∫ 6x² dx = 2x³ + c  ·  ∫ 4x³ dx = x⁴ + c
  • The + c is found from a boundary condition (a point the curve passes through).

WORKED — boundary condition

Given f′(x) = 4x³ and f(1) = 3, find f(x).

f(x) = x⁴ + c. Then 3 = 1 + c, so c = 2 → f(x) = x⁴ + 2.

AREA UNDER A CURVE (5.5)

Area = ∫ab f(x) dx  (for f(x) > 0 — SL keeps it positive)

Worked: ∫₀² (x² + 1) dx = [x³/3 + x]₀² = 8/3 + 2 = 4.67.

📟 GDC — definite integral

  1. MENU → 1 (RUN·MAT) → OPTN → F4 (CALC)
  2. F1 (∫dx) → type ∫(x² + 1, 0, 2) → EXE → 4.6667

Or graph it: GRAPH → F5 G-SOLVE → F6 (▸) → F1 (∫dx) → set lower/upper bounds.

5.5 · 5.6 · 5.7 · 5.8

Max, min, optimisation & trapezoidal rule

Stationary points, using them to optimise, and estimating areas.

STATIONARY POINTS (5.5 · 5.6)

  1. Solve f′(x) = 0 to find the x-value(s).
  2. Find the y-value: plug back into f.
  3. Classify: check the sign of f′ on either side (or use f″). + → − is a max, − → + is a min.

Worked: f(x) = x² − 4x + 3 → f′(x) = 2x − 4 = 0 → x = 2. f(2) = −1. f″ = 2 > 0, so minimum at (2, −1).

📟 GDC — find the max/min directly

  1. MENU 5 (GRAPH) → type Y1 = x² − 4x + 3 → F6 (DRAW)
  2. F5 (G-SOLVE) → F3 (MIN) → (2, −1)  (F2 for a MAX)

OPTIMISATION (5.7)

  1. Write the quantity to maximise/minimise as a function of one variable.
  2. Differentiate and set f′(x) = 0.
  3. Solve for x, confirm it's a max/min, and state the answer with units.

"Find the maximum area / minimum cost / largest volume" — same recipe every time.

TRAPEZOIDAL RULE (5.8)

A ≈ (h/2)[y₀ + 2(y₁ + y₂ + … + yn−1) + yn],  h = (b − a)/n

Worked: ∫₀² (x² + 1) dx with 4 strips (h = 0.5). y-values 1, 1.25, 2, 3.25, 5 → A ≈ 0.25 × 19 = 4.75.

Trap: first and last y counted once, everything in the middle counted twice.

SELF-TEST ✍

No notes. Pick an answer, get instant feedback.

1. d/dx (5x³) = ?

✅ 15x². 5 × 3x³⁻¹.
❌ 5x³ → 5×3x² = 15x².

2. d/dx (x² + 3x) = ?

✅ 2x + 3. Term by term.
❌ x² → 2x, 3x → 3, giving 2x + 3.

3. ∫ 6x² dx = ?

✅ 2x³ + c. Add one to the power, divide: 6x³/3.
❌ 6x² → 6x³/3 = 2x³, plus the constant + c.

4. The gradient of f(x) = x³ at x = 2 is:

✅ 12. f′(x) = 3x², f′(2) = 12.
❌ f′(x) = 3x², f′(2) = 3(4) = 12.

5. The stationary point of f(x) = x² − 6x + 5 is at:

✅ x = 3. f′(x) = 2x − 6 = 0.
❌ 2x − 6 = 0, so x = 3.

6. If f′(x) < 0 for all x, the function is:

✅ Decreasing. Negative gradient → falling.
❌ f′ < 0 → the curve slopes down → decreasing.

🎯 EXAM WALKTHROUGHS

Q1 — DIFFERENTIATE [2 marks] "Differentiate f(x) = 2x³ − 5x² + x − 7."

Model answer: f′(x) = 6x² − 10x + 1 (2 marks — all three terms correct; the −7 → 0).

Q2 — CALCULATE [3 marks] "Find the equation of the tangent to f(x) = x² at x = 1."

Model answer: f′(x) = 2x so m = 2 (1) · point (1, 1) (1) · y − 1 = 2(x − 1) → y = 2x − 1 (1).

Q3 — CALCULATE [3 marks] "Given f′(x) = 4x³ and f(1) = 3, find f(x)."

Model answer: f(x) = x⁴ + c (1) · 3 = 1 + c → c = 2 (1) · f(x) = x⁴ + 2 (1).

Trap: forgetting the + c loses the whole second half of the question.

Q4 — CALCULATE [3 marks] "Find and classify the stationary point of f(x) = x² − 4x + 3."

Model answer: f′(x) = 2x − 4 = 0 → x = 2 (1) · f(2) = −1 (1) · f″ = 2 > 0 so minimum at (2, −1) (1).

Trap: "stationary point" needs the coordinates AND the max/min classification.
