📖 Definitions bank

THE WORDS THAT SCORE

Exact definitions, one line each.

TermDefinition
Derivative f′(x)The gradient function — the slope of the curve, and the instantaneous rate of change of y with respect to x.
Increasing functionA function where f′(x) > 0 — the curve is going up.
Decreasing functionA function where f′(x) < 0 — the curve is going down.
Stationary pointWhere f′(x) = 0 — the curve is momentarily flat (a max, min, or point of inflection).
TangentA straight line that touches the curve at one point, with gradient f′(x) there.
NormalThe line perpendicular to the tangent at the same point.
Integration (anti-differentiation)The reverse of differentiation: given f′(x), recover f(x).
Definite integralThe signed area under a curve between two x-values.
Local maximum / minimumThe highest / lowest value of a function in a small neighbourhood around a point.
OptimisationFinding the maximum or minimum value of a quantity by setting its derivative to zero.

THE FORMULAS YOU MUST KNOW

All SL calculus is the power rule, forward and backward.

FormulaWhat it doesNotes
d/dx (axⁿ) = an xⁿ⁻¹The power rule (differentiate)multiply by the power, drop it by one
f(x) = axⁿ + bxⁿ⁻¹ + …Polynomial derivativedifferentiate term by term; constants vanish
y − y₁ = m(x − x₁)Tangent (and normal) equationm = f′(x₁) for tangent; m = −1/f′(x₁) for normal
∫ axⁿ dx = a·xⁿ⁺¹/(n+1) + cIndefinite integraln ≠ −1 (that's the log rule, not SL)
+ c, found via a boundary conditionConstant of integrationgiven f(1) = 5, plug in and solve for c

A ≈ (h/2)[y₀ + 2(y₁ + y₂ + … + yₙ₋₁) + yₙ]Trapezoidal ruleh = strip width = (b − a)/n
EXAM TRAP — the constant of integration. ∫ always gets a "+ c". You only find it from a boundary condition (a point the curve passes through). Forgetting "+ c" on a "find f(x)" question loses a mark every time.
🔢 Key facts

NUMBERS TO HAVE LOADED

  • f′(x) > 0 → increasing · f′(x) < 0 → decreasing · f′(x) = 0 → stationary point.
  • Stationary point test: find x where f′(x) = 0, then check the sign of f′ on either side (or use f″). Sign goes + → − = max; − → + = min.
  • Rate of change: the derivative IS a rate. "The rate at which the volume changes" = dV/dt. Units come from the units of y per unit of x.
  • Power rule in reverse for integration: add one to the power, divide by the new power. ∫x² dx = x³/3 + c.
  • Area under the curve is only straight ∫f(x)dx when f stays positive. SL questions keep f(x) > 0, so the GDC gives the answer directly.
  • Optimisation (5.7): write the quantity to maximise as a function of one variable, differentiate, set f′(x) = 0, solve, confirm it's a max/min.
🎯 Worked examples

SIX QUESTIONS, STEP BY STEP

Model answers with the trap that catches people on each one.

1. Differentiate f(x) = 3x⁴.
f′(x) = 3 × 4x³ = 12x³.
Trap: multiply by the power AND drop it by one. 3x⁴ → 12x³, not 3x³ or 12x⁴.
2. Differentiate f(x) = 2x³ − 5x² + x − 7.
f′(x) = 6x² − 10x + 1. The constant −7 differentiates to 0.
Trap: constants vanish when you differentiate. The −7 is gone, not carried along.
3. Find the equation of the tangent to f(x) = x² at x = 1.
f′(x) = 2x, so m = f′(1) = 2. At x = 1, y = 1. y − 1 = 2(x − 1) → y = 2x − 1.
Trap: you need BOTH the gradient (from f′) and the point (from f). Skipping the point and writing y = 2x loses the intercept.
4. Given f′(x) = 4x³ and f(1) = 3, find f(x).
f(x) = x⁴ + c. Then 3 = 1⁴ + c, so c = 2. f(x) = x⁴ + 2.
Trap: without the boundary condition, f(x) = x⁴ + c could be anything. The given point pins down c = 2.
5. Find and classify the stationary point of f(x) = x² − 4x + 3.
f′(x) = 2x − 4 = 0 → x = 2. f(2) = −1. f″(x) = 2 > 0, so minimum at (2, −1).
Trap: "stationary point" needs coordinates (2, −1), and you must say whether it's a max or min — just "x = 2" is half the answer.
6. Use the trapezoidal rule with 4 strips to estimate ∫₀² (x² + 1) dx.
h = 0.5. y-values: 1, 1.25, 2, 3.25, 5. A ≈ (0.5/2)[1 + 2(1.25 + 2 + 3.25) + 5] = 0.25 × 19 = 4.75 (exact value ≈ 4.67).
Trap: the first and last y-values are counted once, everything in between twice. Forgetting that ×2 in the middle is the classic slip.
✏️ Self-test

QUICK QUIZ — 6 QUESTIONS

No notes. Pick an answer and get told right away.

Q1. d/dx (5x³) = ?

✅ 15x². Multiply by 3, drop the power by one: 5×3x².
❌ 5x³ → 5×3x³⁻¹ = 15x².

Q2. d/dx (x² + 3x) = ?

✅ 2x + 3. Term by term: 2x¹ + 3·1·x⁰.
❌ x² → 2x, and 3x → 3, giving 2x + 3.

Q3. ∫ 6x² dx = ?

✅ 2x³ + c. Add one to the power (3), divide by 3: 6x³/3.
❌ 6x² → 6x³/3 = 2x³, plus the constant + c.

Q4. The gradient of f(x) = x³ at x = 2 is:

✅ 12. f′(x) = 3x², so f′(2) = 12.
❌ f′(x) = 3x², so f′(2) = 3(4) = 12.

Q5. The stationary point of f(x) = x² − 6x + 5 is at:

✅ x = 3. f′(x) = 2x − 6 = 0 → x = 3.
❌ 2x − 6 = 0, so x = 3.

Q6. If f′(x) < 0 for all x, the function is:

✅ Decreasing. Negative gradient means the curve is falling.
❌ f′ < 0 → the curve slopes down → decreasing.
