2.1

Straight lines

The gradient-intercept form and the two line relationships that show up every year.

y = mx + c

m = gradient (slope), c = y-intercept. Gradient through two points: m = (y₂ − y₁)/(x₂ − x₁).

  • Parallel lines: m₁ = m₂ (same gradient, different intercept).
  • Perpendicular lines: m₁ × m₂ = −1, so the perpendicular gradient is −1/m (flip and change the sign).
  • Equation through a point: y − y₁ = m(x − x₁).

WORKED

Find the equation of the line through (1, 2) and (3, 8).

m = (8 − 2)/(3 − 1) = 3. Then y − 2 = 3(x − 1) → y = 3x − 1.

A line with gradient 3 is perpendicular to one with gradient −1/3.

2.2

Functions & inverses

Domain, range, and the inverse as a reflection in y = x.

FUNCTION, DOMAIN, RANGE

A function maps every input x to exactly one output y.

  • Domain = all possible x (input) values.
  • Range = all possible y (output) values.
  • Notation: f(x), v(t), C(n) — the letter just names the function.
🔁

The inverse function f⁻¹

reverses what f does — its graph is a reflection in y = x

  1. Write the function as y = …
  2. Swap x and y.
  3. Solve for y — that's f⁻¹(x).

Check: f(2) = 7 for f(x) = 2x + 3, so f⁻¹(7) must equal 2. If it doesn't, you slipped.

WORKED — inverse

Find f⁻¹(x) for f(x) = 2x + 3.

x = 2y + 3 → 2y = x − 3 → f⁻¹(x) = (x − 3)/2.

2.3 · 2.4

Graphs & key features

The features an examiner asks for, and the G-Solve keys that find them for you.

KEY FEATURES OF A GRAPH

  • x-intercept = where y = 0 (the roots / zeros).
  • y-intercept = where x = 0.
  • Maximum / minimum (vertex of a parabola) = the turning point.
  • Asymptotes = lines the curve approaches but never reaches.
  • Point of intersection of two curves = where f(x) = g(x).

WORKED — intersection of two curves

Find where y = x² − 4x + 5 meets y = 2x − 3.

📟 GDC — fx-CG50 (G-Solve)

  1. MENU → 5 (GRAPH)
  2. Type Y1 = x² − 4x + 5, Y2 = 2x − 3 → F6 (DRAW)
  3. F5 (G-SOLVE) → F5 (ISCT) → reads off the intersection point(s)

G-Solve is your whole toolbox for "key features": F1 ROOT (x-intercepts), F2 MAX, F3 MIN, F5 ISCT (intersection).

WORKED — vertex of a parabola

Find the vertex of f(x) = x² − 4x + 5.

By hand: axis x = −b/2a = 2, vertex (2, 1). On the GDC: graph it → F5 G-SOLVE → F3 (MIN) → (2, 1).

2.5 · 2.6

Models & modelling

The six model shapes you fit to data, and how the GDC does the fitting.

LINEAR

f(x) = mx + c

Straight line, constant rate of change.

QUADRATIC

f(x) = ax² + bx + c

Parabola. Axis of symmetry x = −b/2a, vertex, roots via the quadratic formula.

EXPONENTIAL

f(x) = kaˣ + c

Growth/decay. Horizontal asymptote y = c.

CUBIC

f(x) = ax³ + bx² + cx + d

Up to 3 roots, 2 turning points.

POWER

f(x) = axⁿ

Direct (n > 0) / inverse (n < 0 → vertical asymptote at x = 0).

SINUSOIDAL

f(x) = a sin(bx) + d

Amplitude |a|, period 2π/b, midline y = d.

FITTING A MODEL TO DATA (2.6)

The modelling loop: choose a model (from the shape of the data) → fit the parameters (GDC regression) → test it (does it make sense?) → use it (predict).

📟 GDC — fit a regression line (linear model)

  1. MENU → 2 (STAT)
  2. Enter x-values in List 1, y-values in List 2
  3. F2 (CALC) → F3 (REG) → F1 (X, linear)
  4. Reads off a, b and the correlation r

⚠️ Casio writes the line as y = a + bx (a = intercept, b = gradient). If the question uses y = ax + b, the letters swap — read the numbers, not the letters.

📟 GDC — other models

  1. Quadratic: STAT → F2 CALC → F3 REG → F3 (X²)
  2. Exponential: F3 REG → F6 (▸) → F2 (Exp)
  3. Sinusoidal: F3 REG → F6 (▸) → F4 (Sin)
Question-type guide

HOW TO SOLVE THE COMMON QUESTIONS 🎯

The method for each question type, the concept to remember, and a worked answer.

TYPE 1 · CALCULATE

Equation of a line, parallel & perpendicular

  1. Find the gradient m = (y₂ − y₁)/(x₂ − x₁) from two points.
  2. Use the point-slope form y − y₁ = m(x − x₁).
  3. Parallel → same m. Perpendicular → m = −1/m (negative reciprocal).
WORKED — line through (1, 2) and (3, 8); perpendicular gradient

m = (8 − 2)/(3 − 1) = 3 → y = 3x − 1; a perpendicular line has gradient −1/3.

🧠 CONCEPTS TO REMEMBER: perpendicular gradient = −1/m (flip the fraction AND the sign); consistent point ordering (second minus first).
TYPE 2 · CALCULATE

Find the inverse function

  1. Write the function as y = ….
  2. Swap x and y.
  3. Solve for y — that's f⁻¹(x).
WORKED — f(x) = 2x + 3 → f⁻¹(x)

x = 2y + 3 → 2y = x − 3 → f⁻¹(x) = (x − 3)/2. Check: f(2) = 7, f⁻¹(7) = 2.

🧠 CONCEPTS TO REMEMBER: the inverse graph is a reflection in y = x; check it undoes the original.
TYPE 3 · STATE

Domain and range

  1. Domain = all allowed x (inputs) — look for restrictions (can't divide by 0, can't take a root of a negative, the context may limit it).
  2. Range = all possible y (outputs) — for a quadratic, find the vertex and which way it opens.
  3. For a model, the domain is usually the sensible physical range.
WORKED — f(x) = x² − 4x + 5

It's a parabola opening up with vertex (2, 1), so range is y ≥ 1.

🧠 CONCEPTS TO REMEMBER: domain = x-values, range = y-values; 'domain' in a context = what makes sense in the real problem.
TYPE 4 · CALCULATE

Parabola features — vertex, axis, roots

  1. Axis of symmetry: x = −b/(2a).
  2. Vertex: plug that x back in to get y → (−b/2a, f(−b/2a)).
  3. Roots (x-intercepts): solve f(x) = 0 (factorise, quadratic formula, or GDC).
  4. Opens up (a > 0 → min) or down (a < 0 → max).
WORKED — f(x) = x² − 4x + 5

axis x = 2; vertex (2, 1) minimum; discriminant b²−4ac = 16−20 = −4 < 0, so no real roots (never crosses the x-axis).

🧠 CONCEPTS TO REMEMBER: axis is a line (x = 2); vertex is a point (2, 1); discriminant tells you how many roots.
TYPE 5 · CALCULATE (GDC)

Point of intersection of two curves

  1. Graph both functions: MENU 5 (GRAPH) → type Y1, Y2 → F6 DRAW.
  2. F5 (G-SOLVE) → F5 (ISCT) → reads the intersection (x, y).
  3. Checking: the x-value satisfies both equations (where f(x) = g(x)).
WORKED — where y = x² − 4x + 5 meets y = 2x − 3

G-Solve ISCT gives the intersection point(s); equate x²−4x+5 = 2x−3 and solve for x to check.

🧠 CONCEPTS TO REMEMBER: intersection = solving f(x) = g(x); the GDC does this instantly, but write the equation for the method marks.
TYPE 6 · MODEL & USE

Fit a model and use it to predict

  1. Look at the shape of the data → choose linear, quadratic, exponential, cubic or sinusoidal.
  2. Enter x in List 1, y in List 2 → F2 CALC → F3 REG → F6 (▸) → choose the model type.
  3. Read the parameters (Casio: y = a + bx — a = intercept, b = gradient — mind the letter swap).
  4. Use the model only INSIDE the data range (no extrapolation).
WORKED — fit a line and predict y when x = 8 (data spans x = 2 to 6)

You get y = a + bx; predicting at x = 8 is extrapolation — say it's unreliable, then give the number.

🧠 CONCEPTS TO REMEMBER: this is 2.6 — every mark is in 'choose the right model' + 'justify' + 'don't extrapolate'.

SELF-TEST ✍

No notes. Pick an answer, get instant feedback.

1. The gradient of the line through (2, 3) and (6, 11) is:

✅ 2. (11 − 3)/(6 − 2) = 8/4 = 2.
❌ m = (11 − 3)/(6 − 2) = 8/4 = 2.

2. A line has gradient 4. A perpendicular line has gradient:

✅ −1/4. Perpendicular = negative reciprocal.
❌ m₁m₂ = −1, so m₂ = −1/4.

3. The axis of symmetry of y = x² − 6x + 8 is:

✅ x = 3. x = −b/(2a) = 6/2 = 3.
❌ x = −b/(2a) = −(−6)/(2×1) = 3.

4. The horizontal asymptote of f(x) = 2(3ˣ) + 5 is:

✅ y = 5. As x → −∞, 3ˣ → 0, so f(x) → 5.
❌ The "+ 5" sets the asymptote at y = 5.

5. The inverse of f(x) = 4x − 7 is:

✅ (x + 7)/4. Swap: x = 4y − 7 → y = (x + 7)/4.
❌ x = 4y − 7, so 4y = x + 7 → f⁻¹(x) = (x + 7)/4.

6. The amplitude of f(x) = 3 cos(2x) + 1 is:

✅ 3. Amplitude = |a| = 3; the +1 only shifts the midline.
❌ Amplitude is |a| = 3, not the vertical shift.

🔢 DATA BANK — NUMBERS TO OWN

  • Quadratic discriminant b² − 4ac: > 0 two x-intercepts, = 0 one (touches), < 0 none.
  • a > 0 parabola opens up (min); a < 0 opens down (max).
  • Exponential kaˣ + c levels off at y = c (as x → −∞ when a > 1).
  • Sinusoid a sin(bx) + d: range is [d − |a|, d + |a|].
  • Direct variation (n > 0) passes through the origin; inverse (n < 0) shoots up by the y-axis.

🎯 EXAM WALKTHROUGHS

Q1 — CALCULATE [2 marks] "Find the equation of the line through (1, 2) and (3, 8)."

Model answer: m = (8 − 2)/(3 − 1) = 3 (1) · y − 2 = 3(x − 1) → y = 3x − 1 (1).

Q2 — CALCULATE [2 marks] "Find the vertex of f(x) = x² − 4x + 5."

Model answer: axis x = −b/2a = 2 (1) · vertex = (2, 1), a minimum since a > 0 (1).

Trap: the axis is the line x = 2; the vertex is the point (2, 1). Missing the y-coordinate loses the mark.

Q3 — CALCULATE [2 marks] "State the horizontal asymptote of f(x) = 3(2ˣ) + 1."

Model answer: as x → −∞, 2ˣ → 0 so f(x) → 1, giving y = 1 (write "y = 1", not just "1").

Q4 — CALCULATE [2 marks] "For f(x) = 5 sin(2x) + 3, state the amplitude and period."

Model answer: amplitude = 5 (1) · period = 2π/2 = π (1).
