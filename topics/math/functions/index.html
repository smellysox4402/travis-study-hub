📖 Definitions bank

THE WORDS THAT SCORE

Exact definitions, one line each.

TermDefinition
FunctionA rule that maps every input x to exactly one output y. f(x), v(t), C(n) are all functions.
DomainThe set of all possible input (x) values a function accepts.
RangeThe set of all possible output (y) values the function produces.
Inverse function f⁻¹Reverses a function: if f takes x → y, then f⁻¹ takes y back to x. Its graph is a reflection in the line y = x.
Gradient (slope)Rate of change of y with respect to x — how steep a line is. m in y = mx + c.
InterceptWhere a graph crosses an axis. x-intercept = where y = 0; y-intercept = where x = 0.
AsymptoteA line the curve approaches but never reaches. Exponential curves have a horizontal one; inverse-variation curves have a vertical one.
VertexThe turning point of a parabola — its maximum or minimum.
Axis of symmetryThe vertical line through a parabola's vertex that splits it into two mirror-image halves.
Root / zeroAn x-value where f(x) = 0 — where the graph cuts the x-axis.
Periodic functionRepeats the same shape at regular intervals — sine and cosine repeat every period.

🔢 Key facts

NUMBERS TO HAVE LOADED

  • Quadratic discriminant b² − 4ac: positive = two x-intercepts, zero = one (touches), negative = none (never crosses).
  • a > 0 → parabola opens up (minimum vertex); a < 0 → opens down (maximum).
  • Exponential asymptote: for kaˣ + c the curve levels off at y = c (as x → −∞ when a > 1). Write "y = c", not just "c".
  • Sinusoid a sin(bx) + d: amplitude = |a|, period = 2π/b (radians) or 360°/b (degrees), midline y = d, so range is [d − |a|, d + |a|].
  • Direct variation f(x) = axⁿ with n > 0 passes through the origin; inverse variation (n < 0) shoots up next to the y-axis.
  • GDC graphs sums/differences of functions and finds intersections of two curves (2.4) — always sketch what's on screen before you transfer it to paper.
🎯 Worked examples

SIX QUESTIONS, STEP BY STEP

Model answers with the trap that catches people on each one.

1. Find the equation of the line through (1, 2) and (3, 8).
m = (8 − 2)/(3 − 1) = 3. Using y − y₁ = m(x − x₁): y − 2 = 3(x − 1) → y = 3x − 1.
Trap: "rise over run" is (y₂ − y₁)/(x₂ − x₁). Swapping the pairs gives the right number here, but not when signs differ — always second point minus first, consistently.
2. A line has gradient 3. Find the gradient of a line perpendicular to it.
Perpendicular gradient is the negative reciprocal: m = −1/3.
Trap: m₁m₂ = −1, so the perpendicular gradient is −1/m. Don't just flip the sign — flip the fraction too.
3. For f(x) = x² − 4x + 5, find the axis of symmetry and the vertex.
Axis: x = −b/(2a) = 4/2 = 2. Vertex y = f(2) = 4 − 8 + 5 = 1. Axis x = 2, vertex (2, 1) — a minimum since a > 0.
Trap: the axis is x = 2 (a line), the vertex is (2, 1) (a point). Missing the y-coordinate of the vertex loses the mark.
4. State the horizontal asymptote of f(x) = 3(2ˣ) + 1.
As x → −∞, 2ˣ → 0, so f(x) → 1. Horizontal asymptote: y = 1.
Trap: it's the "+ c" that sets the asymptote. The 3 only stretches the curve, it never moves the asymptote off y = 1.
5. Find the inverse of f(x) = 2x + 3.
Swap x and y: x = 2y + 3 → 2y = x − 3 → f⁻¹(x) = (x − 3)/2.
Trap: check with f(2) = 7, then f⁻¹(7) = 2. If the inverse doesn't undo the original, you've made an algebra slip.
6. For f(x) = 5 sin(2x) + 3, state the amplitude, period and midline.
Amplitude = 5, period = 2π/2 = π, midline y = 3 (so the range is −2 to 8).
Trap: the "+ d" shifts the whole curve but does not change the amplitude. Amplitude is |a| = 5, not 8.
✏️ Self-test

QUICK QUIZ — 6 QUESTIONS

No notes. Pick an answer and get told right away.

Q1. The gradient of the line through (2, 3) and (6, 11) is:

✅ 2. (11 − 3)/(6 − 2) = 8/4 = 2.
❌ m = (11 − 3)/(6 − 2) = 8/4 = 2.

Q2. A line has gradient 4. A perpendicular line has gradient:

✅ −1/4. Perpendicular gradient = negative reciprocal.
❌ m₁m₂ = −1, so m₂ = −1/4.

Q3. The axis of symmetry of y = x² − 6x + 8 is:

✅ x = 3. x = −b/(2a) = 6/2 = 3.
❌ x = −b/(2a) = −(−6)/(2×1) = 3.

Q4. The horizontal asymptote of f(x) = 2(3ˣ) + 5 is:

✅ y = 5. As x → −∞, 3ˣ → 0, so f(x) → 5.
❌ The "+ 5" sets the asymptote at y = 5.

Q5. The inverse of f(x) = 4x − 7 is:

✅ (x + 7)/4. Swap x and y: x = 4y − 7 → y = (x + 7)/4.
❌ x = 4y − 7, so 4y = x + 7, giving f⁻¹(x) = (x + 7)/4.

Q6. The amplitude of f(x) = 3 cos(2x) + 1 is:

✅ 3. Amplitude = |a| = 3. The +1 only shifts the midline.
❌ Amplitude is the multiplier |a| = 3, not the vertical shift.
