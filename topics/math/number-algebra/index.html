1.1 · 1.6

Scientific notation & bounds

Writing big and small numbers cleanly, and knowing how far a rounded number can really lie.

SCIENTIFIC NOTATION — a × 10k

1 ≤ a < 10, and k is an integer. The whole point is a single non-zero digit in front of the decimal point.

  • 4 300 000 = 4.3 × 106 (move the point 6 places left)
  • 0.0045 = 4.5 × 10−3 (move the point 3 places right)
  • On the GDC use the ×10x key (or set the display to Sci) to enter and read these.

UPPER & LOWER BOUNDS

A rounded number is off by at most half a unit in the last place.

GivenLower boundUpper bound
6.7 m (1 dp)6.65 m6.75 m (strict <)
250 (2 sf)245255

Lower bound is inclusive (≥), upper bound is exclusive (<) — a value of exactly 6.75 would round UP to 6.8.

PERCENTAGE ERROR

% error = |measured − exact| / exact × 100%

A length of 6.7 m (1 dp) has max error 0.05 m, so max % error = 0.05 / 6.7 × 100 ≈ 0.75%.

1.2 · 1.3

Sequences & series

Arithmetic (add a fixed d) vs geometric (multiply by a fixed r) — and their sums.

➕➖

Arithmetic — a constant difference

5, 8, 11, 14, … has d = 3

n-th term: un = u1 + (n − 1)d

Sum: Sn = n/2 [2u1 + (n − 1)d] = n/2 (u1 + un)

✖️

Geometric — a constant ratio

8, 4, 2, 1, … has r = ½

n-th term: un = u1 rn−1

Sum: Sn = u1(1 − rn)/(1 − r) · sum to infinity: S∞ = u1/(1 − r), only if |r| < 1

EXAM TRAP: arithmetic vs geometric — if terms change by a constant amount it's arithmetic (use d); if they're multiplied each time it's geometric (use r). "Doubles", "halves", "5% each year" all scream geometric.

WORKED — arithmetic

Find u10 and S10 for 5, 8, 11, …

d = 3. u10 = 5 + 9(3) = 32. S10 = 10/2 (5 + 32) = 5 × 37 = 185.

Trap: the 10th term uses (n − 1) = 9, not 10.

WORKED — geometric sum to infinity

Evaluate 8 + 4 + 2 + 1 + …

r = ½, so S∞ = 8 / (1 − ½) = 16.

Trap: S∞ only exists when |r| < 1. r ≥ 1 means the series grows forever with no finite sum.

1.4 · 1.7

Financial mathematics

Compound interest, depreciation, annuities and loans — all one geometric idea wearing different clothes.

1.4 · GROWTH

Compound interest

FV = PV (1 + i)n

i = rate per period, n = number of periods. Interest on interest — geometric growth.

1.4 · DECAY

Annual depreciation

FV = PV (1 − r)n

Value falls by a fixed % each year — geometric with ratio < 1.

1.7 · SAVING

Annuity

Equal regular payments into an account that earns interest (pension / savings plan).

1.7 · BORROWING

Amortization

Paying off a loan with regular payments — each one covers interest plus some principal.

WORKED — compound interest

$2500 at 3.5% p.a. compounded annually. Value after 6 years?

FV = 2500(1.035)6 = $3073.14.

📟 GDC — fx-CG50 (TVM app)

  1. MENU → open Financial (TVM) → EXE
  2. Press F2 (Compound Interest, CMPD)
  3. Set n = 6, I% = 3.5, PV = −2500, PMT = 0, P/Y = 1, C/Y = 1
  4. Move the cursor to FV → press SOLVE (soft key) → 3073.14

Sign rule: money you hand over (PV you invest) is negative; money you get back (FV) comes out positive.

WORKED — depreciation

A laptop bought for $1200 depreciates 15% per year. Value after 4 years?

FV = 1200(1 − 0.15)4 = 1200(0.85)4 = $626.41.

Trap: depreciation multiplies by (1 − r), never (1 + r) — using 1.15 makes a laptop that gains value.

EXAM TRAP — ANNUITIES: an annuity is just a savings plan: fixed PMT each period, PV = 0, solve for FV. A loan (amortization) is the reverse: PV = the amount borrowed, solve for PMT. The same TVM screen does both — you just solve for a different field.
1.5 · 1.8

Exponents, logs & GDC solving

The laws of powers and logs, and how the calculator solves equations you can't rearrange by hand.

LAWS OF EXPONENTS

  • am · an = am+n  ·  am/an = am−n
  • (am)n = amn  ·  a0 = 1  ·  a−n = 1/an

LAWS OF LOGARITHMS

A logarithm is the inverse of a power: log10 1000 = 3 because 10³ = 1000.

  • loga(xy) = logax + logay  ·  loga(x/y) = logax − logay
  • logaxm = m logax  ·  logaa = 1  ·  loga1 = 0

ln is log base e (e ≈ 2.718): ln e = 1, ln 1 = 0.

WORKED — solving with logs

Solve 10x = 500.

x = log10 500 ≈ 2.699.

📟 GDC — fx-CG50

  1. MENU → 1 (RUN·MAT)
  2. Press log → type 500 → EXE → 2.699

Sanity check: log10 500 sits between 2 (log 100) and 3 (log 1000) — the power, not a count.

GDC SOLVING (1.8)

Two jobs the GDC does that you should never do by hand: solving systems of linear equations (up to 3 unknowns) and polynomial equations.

📟 GDC — solve a polynomial (e.g. x² − 5x + 6 = 0)

  1. MENU → A (EQUA) → EXE
  2. Press F2 (POLY) → F1 (degree 2: ax² + bx + c)
  3. Type a = 1, b = −5, c = 6 → EXE after each
  4. F1 (SOLVE) → x = 2, 3

📟 GDC — solve simultaneous equations (up to 3 unknowns)

  1. MENU → A (EQUA) → EXE
  2. Press F1 (SIMUL) → F1 (2 unknowns) or F2 (3 unknowns)
  3. Type the coefficients of each equation → EXE after each
  4. F1 (SOLVE) → gives x, y [, z]

📟 GDC — solve ANY single equation (Solve-N)

  1. MENU → 1 (RUN·MAT) → OPTN → F4 (CALC)
  2. Press F1 (SolveN) → type SolveN(10^x = 500, x) → EXE

SolveN is your safety net for any equation that isn't a neat polynomial — exponential, log, anything.

SELF-TEST ✍

No notes. Pick an answer, get instant feedback.

1. Find the 10th term of the arithmetic sequence 3, 7, 11, …

✅ 39. u10 = 3 + 9×4 = 39.
❌ d = 4, so u10 = 3 + (10−1)×4 = 3 + 36 = 39.

2. The sum to infinity of 12 + 6 + 3 + … is:

✅ 24. r = ½, so S∞ = 12/(1 − ½) = 24.
❌ S∞ = u1/(1 − r) = 12/(1 − 0.5) = 24.

3. $2000 at 4% p.a. compounded annually for 5 years is worth:

✅ $2433.31. 2000(1.04)⁵ = 2433.31.
❌ 2000 × 1.04⁵ = 2000 × 1.21665 = $2433.31.

4. log10 10 000 = ?

✅ 4. 10⁴ = 10 000.
❌ The log is the power: 10 000 = 10⁴ → 4.

5. A value is given as 8.3 (1 dp). The lower bound is:

✅ 8.25. Rounding to 1 dp is off by at most 0.05.
❌ 1 dp → half of 0.1 is 0.05, so 8.3 − 0.05 = 8.25.

6. The sum of the first 8 terms of 2, 5, 8, … is:

✅ 100. S₈ = 8/2(2×2 + 7×3) = 4 × 25 = 100.
❌ d = 3, u₁ = 2: S₈ = 4(4 + 21) = 100.

🎯 EXAM WALKTHROUGHS

Q1 — CALCULATE [3 marks] "Find the 20th term and the sum of the first 20 terms of 3, 7, 11, …"

Model answer: d = 4 (1) · u20 = 3 + 19×4 = 79 (1) · S20 = 20/2(3 + 79) = 820 (1).

Trap: u20 uses (n − 1) = 19. Writing 3 + 20×4 = 83 is the classic slip.

Q2 — CALCULATE [2 marks] "$5000 is invested at 2.5% p.a. compounded annually. Find the value after 10 years."

Model answer: FV = 5000(1.025)10 = $6400.42 (2 marks — method + answer).

Q3 — EXPLAIN [2 marks] "Why does the sum to infinity of 1 + 2 + 4 + 8 + … not exist?"

Model answer: the common ratio is r = 2 (1), and since |r| ≥ 1 the terms grow without limit, so there is no finite sum to infinity (1).

Q4 — CALCULATE [2 marks] "A distance is 6.7 m correct to 1 dp. State the bounds and the maximum percentage error."

Model answer: 6.65 m ≤ d < 6.75 m (1) · % error = 0.05/6.7 × 100 = 0.75% (1).
